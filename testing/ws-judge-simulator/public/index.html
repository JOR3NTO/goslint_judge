SubmissionController exige un rol vía @PreAuthorize, pero todavía no hay filtro JWT para peticiones HTTP (solo el handshake del WebSocket valida el token de verdad). Con AUTH_BYPASS=true en backend/.env, submission-service registra un bypass temporal (TemporaryAuthBypassFilter) que autentica cualquier petición REST con todos los roles, así que este botón funciona sin necesidad de un token válido. Si el bypass está desactivado, responde 403.
